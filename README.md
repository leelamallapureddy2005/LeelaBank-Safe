# LeelaBank-Safe 🔐 | Full Stack Secure Banking System

**Live Repo:** https://github.com/leelamallapureddy2005/LeelaBank-Safe
**Developer:** Leela Mallapureddy | Java Full Stack Developer | B.Tech CSE

## 🚀 Features
- Secure Account Creation & Login Authentication
- Deposit, Withdraw, Fund Transfer
- Balance Enquiry & Transaction History
- File-based Persistence (accounts.txt)
- Responsive UI - 3 Pages (Login, Create, Dashboard)

## 🛠️ Tech Stack
- Backend: Java (BankServer.java) - OOP, File I/O, Exception Handling, Secure Auth
- Frontend: HTML5, CSS3, JavaScript
- Tools: Git, GitHub, VS Code

## 📁 Project Structure
- BankServer.java - Core Banking Logic
- index.html - Login Page
- create.html - Create Account
- dashboard.html - User Dashboard

## ▶️ How to Run
1. Compile: javac BankServer.java
2. Run: java BankServer
3. Open index.html in browser
